# EXODIA agent naming

- Give each agent a distinct first name. In Slack, use that first name as the installed bot's display name so the sidebar stays concise.
- Describe its role in the Slack app's short description and About section. Do not imply it is a person or claim access or automation it does not have.
- In Brain, keep the role beside the name where agents are selected, for example `Elio · AI Scout`. Add a project or client qualifier when needed to distinguish instances.
- Preserve the existing Slack app and bot identities, credentials and channel access when changing names. The installed bot name is managed separately from the developer app name; verify the workspace sidebar after a change.
